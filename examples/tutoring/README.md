# French and German sample lessons

Eight editable lessons cover A1, A2, B1 and B2. The levels are teaching targets,
not placement results or certification. Tutors should adapt the pace and support
to the learner in front of them.

| Level | French | German |
| --- | --- | --- |
| A1 | [Au café](french-a1.yaml): order, ask the price, close politely | [In der Bäckerei](german-a1.yaml): order, understand a price, thank |
| A2 | [On se retrouve samedi ?](french-a2.yaml): propose, negotiate and confirm an outing | [Die Lampe funktioniert nicht](german-a2.yaml): describe a problem and agree an appointment |
| B1 | [Le train est parti](french-b1.yaml): explain an incident and verify a solution | [Ein Fest trotz Regen](german-b1.yaml): compare alternatives and revise a plan |
| B2 | [Deux jours à distance ?](french-b2.yaml): concessions, objections and a conditional recommendation | [Fortbildung, die im Alltag hilft](german-b2.yaml): evaluate reasoning and negotiate a trial |

In a Tutoring space, open **Sample lessons** from the current folder. Filter by
language and level, then **Open lesson** to create an editable copy there. An
explicitly selected student/context is inherited; opening a sample never selects a
student for you or changes the space's language settings. The YAML files are also
available to the teacher's own agent and CLI.

Each lesson has a saved palette, opening and content masters, twelve authored
slides (including an optional transcript on A1 lessons), two questions with keys,
facilitator guidance, and four homework tasks: reading, practice, writing and voice.
Reading homework contains the source text it refers to, so learners do not need
the original deck. Homework reaches learners only when deliberately published in
Notes; tutors can choose shared or individual recipients there.

Listening scripts are supplied in private tutor notes for the tutor to read aloud
in the room. A1 transcripts open as optional details after listening. There are no
missing audio assets or automatic synthetic voices. Learners have their own private
voice-response workflow for homework. All scenarios, prices and timetables are
fictional teaching material.

The eight YAML files are the source used by the in-app gallery. Unit checks parse
and validate each deck, publish its homework, and verify its answer key against the
practice grader. Browser and visual checks are recorded in UC-21.
