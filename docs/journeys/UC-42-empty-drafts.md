# UC-42 — Empty draft fields

New questions, text boxes and homework tasks begin with empty values. Instructions are placeholders, never saved text. A teacher can save, reopen, and clear an unfinished deck. Questions need actual prompts and answers before a session starts; both direct and saved-deck launch APIs enforce this.

The journey checks native placeholders and whitespace validation, unused options, matching pairs, save/reload, rejected launches, and empty API-token labels. With `RUN_DESKTOP_JOURNEY=1`, it also saves and reopens an unfinished local file and a long homework document.
